A curated collection of zero-dependency, single-file browser games and utility web apps designed for instant fun, focus, and relaxation. Every project is a standalone `.html` file, and the Windows launcher opens them all from one hub page.

## 🚀 Quick Start (Windows)

1. Click the **Download Windows Launcher** button above. The ZIP contains `StructuralSensei-Launcher.exe` and all eight `.html` files.
2. Right-click the ZIP and choose **Extract All**, then open the extracted folder.
3. Double-click `StructuralSensei-Launcher.exe`. Your browser opens the hub page.
4. Click any game or app card to launch it in a new tab.
5. Keep the console window open while you play. Close it to stop the launcher.

> **Windows SmartScreen:** Because the launcher is unsigned, Windows may show "Windows protected your PC." Click **More info → Run anyway**.

### 1. Tactical Breach: 3D First-Person Wave Shooter
[![Play In Browser](https://img.shields.io/badge/▶_Play_In_Browser-EF4444?style=for-the-badge)](https://YOUR_USER.github.io/YOUR_REPO/tactical-breach.html) [![View Code](https://img.shields.io/badge/View_Code-1F2937?style=for-the-badge)](./tactical-breach.html)
